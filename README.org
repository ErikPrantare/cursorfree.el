#+title: cursorfree.el
A GNU Emacs package for specifying complex and extensible editor
operations.

* Description
:PROPERTIES:
:CUSTOM_ID: description
:END:
cursorfree.el provides a library for composing complex high-level
editor operations.  Examples include yanking to multiple parts of the
buffer simultaneously, following links displayed in non-selected
windows, and deleting a region while keeping whitespace tidy and
without moving point.

This package also provides a spoken command language using [[https://github.com/ErikPrantare/phony.el][phony.el]] to
allow controlling Emacs using your voice.  Being able to do this was
the motivating goal of this package, and to do that the higher level
operations of this package were required.

This package was inspired by [[https://github.com/cursorless-dev/cursorless/][cursorless]], a package providing similar
faculties for VSCode.

** Required dependencies
:PROPERTIES:

If you intend to use this with voice control, install [[https://github.com/ErikPrantare/phony.el][phony.el]] (unless

** Recommended dependencies
:PROPERTIES:
:CUSTOM_ID: recommended-dependencies
:END:
- [[https://github.com/ErikPrantare/phony.el][phony.el]] if this package is to be used for controlling Emacs by
  voice.
- [[https://github.com/ErikPrantare/hatty.el][hatty.el]] for a way to query arbitrary positions in the visible

- [[https://github.com/magnars/multiple-cursors.el][multiple-cursors.el]] for integration with multiple-cursors.  Useful
  when working with multiple targets at once.

** Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:
To install this package, add the following to your configuration:

#+begin_src elisp
  (use-package cursorfree
    :vc (:url "https://github.com/ErikPrantare/cursorfree.el"
              :branch "master"
              :rev :newest))
#+end_src

** Talon integration
:PROPERTIES:
:CUSTOM_ID: talon-integration
:END:
To use the spoken command language, install [[https://github.com/ErikPrantare/phony.el][phony.el]].  The command
language defined here assumes that the rules ~digit~, ~word~,
~number~, ~any-alphanumeric-key~, and ~symbol-key~ are defined.  This
may be provided by the user or by loading
~phony-talon-community-bindings~ from phony.el.

After that, add the following to your configuration:

#+begin_src elisp
  (use-package cursorfree-phony)
#+end_src

To enable the command language, either utter ~"phony enable cursorfree"~
or add ~(phony-enable-module 'cursorfree)~ to your configuration.

* Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:
The object acted upon by the cursorfree operations are called
/targets/.  Targets can be any elisp object, but are most often
objects representing a region in some buffer.

Operations and target can roughly be divided up into two kinds:
/actions/ and /modifiers/.  An action acts upon targets for some type
of side effect.  This may be removing a certain region, closing a
window, or moving point to a location.  A modifier transforms targets
into new targets, and are the mechanism for specifying more complex
targets for the actions to operate on.  Targets that are available
without the use of modifiers are called /primitives/.

The spoken command language provides a compact domain specific
language for operations.  For example, ~"chuck row 23 block"~ is
interpreted as ~"[chuck] [row 23] [block]"~.  ~"chuck"~ is the action
for deleting a target.  ~"row 23"~ is a primitive, indicating the
region of line 23.  Finally, ~"block"~ is a modifier that expands the
target to contain the whole paragraph in which ~row 23~ appears.  The
effect of this command is to remove the paragraph at line 23.

** Primitives
:PROPERTIES:
:CUSTOM_ID: primitives
:END:
A primitive is a target that can be referred to directly.

|-----------------------------+------------------------------------------|
| Spoken form                 | Description                              |
|-----------------------------+------------------------------------------|
| [color] [shape] <character> | Token under a hatty hat.                 |
| car <character>             | The character itself as a string.        |
| word <word>                 | The word itself as a string.             |
| numb <number>               | The number itself.                       |
| row <number>                | Line with the given number (modulo 100). |
| long row <number>           | Line with the given number (exact).      |
| split <number>              | Window with the given [[https://melpa.org/#/winum][winum.el]] index.    |
| this                        | Point, or region if active.              |
| that                        | The target of the last action.           |
| source                      | The source of the last action.           |
| clip                        | The kill ring.                           |
| primary                     | The primary selection.                   |
| its, itself                 | The result of the last evaluation.       |
|-----------------------------+------------------------------------------|

| drop        | cursorfree-drop           |
| float       | cursorfree-float          |
| puff        | cursorfree-puff           |
|-------------+---------------------------|

Some actions have more complex spoken forms:

- ~bring <target> to/after/before <target>~ invokes
  ~cursorfree-bring~.
- ~move <target> to/after/before <target>~ invokes ~cursorfree-move~.
- ~change <target> [to <target>]~ invokes ~cursorfree-change~.
- ~swap <target> with <target>~ invokes ~cursorfree-swap~.
- ~wrap <target> with <character>~ invokes ~cursorfree-wrap~.
- ~unwrap <target>~ invokes ~cursorfree-unwrap~.
- ~rewrap <target> with <character>~ invokes ~cursorfree-rewrap~.
- ~hunt <target> [in <target>] [context <number>]~ invokes
  ~cursorfree-occur~.

Furthermore, the region between two primitives can be referred to with
~<target> past <target>~, and two or more primitives primitives to be
acted upon (both by modifiers and actions) can be referred to with
~<target> and <target>~.

* Extending cursorfree
:PROPERTIES:
:CUSTOM_ID: extending-cursorfree
:END:
Custom target types can be defined by overriding the generic functions
~cursorfree-get~ and/or ~cursorfree-put~.  This allows many built-in
actions to work on them, particularly "bring".

Custom modifiers and primitives can be added by defining phony rules
that contribute to ~cursorfree-modifier~ and ~cursorfree-primitive~.

* Versioning system
:PROPERTIES:
:CUSTOM_ID: versioning-system
:END:
This project uses [[https://semver.org/][semantic versioning]].  While still on 0.y.z, an
increment of y signals breaking changes.
